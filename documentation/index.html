3. Dark Mode & RTL Implementation

Both Dark Mode and RTL (Right-to-Left for Arabic/Hebrew/Persian) are integrated cleanly via vanilla JavaScript and persisted in the browser's localStorage:

  • Dark Mode: Add data-toggle="theme" to any button. Toggling adds or removes the dark class on the root <html> element.
  • RTL: Add data-toggle="direction" to any button. Toggling modifies the dir="rtl" attribute and mirrors alignment automatically.

4. Dynamic Rental Calculator

The interactive pricing calculator in assets/js/rental-calculator.js computes totals dynamically with damage waivers and security deposits:

// Initializing the calculator on equipment-details.html:
RentalCalculator.init({
    dailyRate: 275,   // Base daily rental rate in USD
    weeklyRate: 1100, // Discounted 7-day rate
    deposit: 500      // Mandatory refundable security deposit
});
